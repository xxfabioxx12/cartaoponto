# 🚀 COPIAR PROJETO PARA GOOGLE DRIVE (SUPER RÁPIDO)

## ⏱️ Tempo: 2-3 minutos

---

## 📋 PASSO 1: Prepare a Pasta

1. Abra **Google Drive Desktop** (Windows)
   - Se não tem: https://www.google.com/drive/download/

2. Localize a pasta sincronizada:
   ```
   C:\My Drive\
   OU
   C:\Users\[seu-usuario]\My Drive\
   ```

3. **Crie uma pasta**: `FS-Celulares-Projeto`
   - Clique direito → Nova pasta

---

## 📂 PASSO 2: Copie o Projeto

### Origem:
```
C:\Users\eufab\OneDrive\Área de Trabalho\FS Celulares
```

### Destino:
```
C:\My Drive\FS-Celulares-Projeto\
```

### Ação:
1. Abra a pasta de origem
2. **Selecione TUDO**: Ctrl+A
3. **Copie**: Ctrl+C
4. Navegue até `C:\My Drive\FS-Celulares-Projeto\`
5. **Cole**: Ctrl+V
6. **Aguarde** (alguns segundos a sincronizar)

---

## ✅ PASSO 3: Verifique

### Online (Google Drive):
1. Acesse: https://drive.google.com
2. Procure pela pasta: `FS-Celulares-Projeto`
3. Clique para ver os arquivos
4. Deve ter:
   - ✅ index.html
   - ✅ .env
   - ✅ schema.sql
   - ✅ Todos os .md

### Local:
```
C:\My Drive\FS-Celulares-Projeto\
└── index.html
└── .env
└── schema.sql
└── README.md
└── ... outros arquivos
```

## 🌐 PASSO 4: Outro Claude Acessa

**No outro PC:**

1. Instale **Google Drive Desktop** (mesma coisa)
2. Faça login com **mesma conta Google**
3. Aguarde sincronização
4. Abra a pasta:
   ```
   C:\My Drive\FS-Celulares-Projeto\
   ```
5. **Pronto!** Acesso 100% completo

## 💡 PRO TIPS

### Dica 1: Disponível Offline
Para funcionar sem internet:
1. Clique direito na pasta
2. "Disponível offline"
3. Pronto! Sincroniza quando conectar

### Dica 2: Compartilhar com Outro Usuário
Se outro Claude tem conta Google diferente:
1. Clique direito → Compartilhar
2. Digite o email
3. Pronto! Outro Claude acessa

### Dica 3: Histórico de Versões
Google Drive guarda histórico:
1. Clique direito no arquivo
2. Versões → Ver todas
3. Restaurar versão anterior se precisar
